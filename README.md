This is a small project which I implemented during my studies.

**Robot Coin Collector** is a simple yet exciting game where the player controls a robot to collect as many coins as possible while avoiding black monsters. The game challenges your reflexes and strategic movement to achieve the highest score without getting caught.

## Features
- Guide the robot using keyboard controls.
- Collect coins to increase your score.
- Avoid black monsters, which end the game upon contact.
- Simple yet engaging gameplay suitable for all ages.

## Installation
To run the game on your local machine, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/your-username/robot-coin-collector.git
   ```
2. Navigate to the project directory:
   ```sh
   cd robot-coin-collector
   ```
3. Install dependencies:
   ```sh
   pip install -r requirements.txt
   ```
   Ensure that Pygame is installed, as it is required to run the game. If not included in `requirements.txt`, install it manually:
   ```sh
   pip install pygame
   ```
4. Run the game:
   ```sh
   python main.py
   ```

## Controls
- **Arrow Keys**: Move the robot
- **Escape**: Exit the game

## Requirements
- Python 3.x
- Pygame
